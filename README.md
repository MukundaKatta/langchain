# LangChain Tutorials

> Hands-On Tutorials for the LangChain LLM Framework

## Overview

A collection of practical tutorials covering LangChain's core concepts — from basic chains to advanced RAG pipelines, agents, and memory systems.

## Topics Covered

- **Chains** — Sequential, router, and transform chains
- **Agents** — ReAct agents, tool use, custom agent types
- **RAG** — Retrieval-augmented generation with vector stores
- **Memory** — Conversation buffer, summary, and entity memory
- **Tools** — Custom tools, API integrations, search
- **Embeddings** — Document embedding and similarity search
- **Output Parsers** — Structured output from LLMs

## Tech Stack

Python, LangChain, OpenAI, ChromaDB, FAISS

## Getting Started

```bash
git clone https://github.com/MukundaKatta/langchain.git
cd langchain
pip install -r requirements.txt
jupyter notebook
```
